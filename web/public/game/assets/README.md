# Asset credits

Character meshes, animations, arena, card illustrations and ability icons are original procedural artwork in this repository. Clash Royale screenshots were used as mobile layout references only.

- **Troop sounds** (`sfx/tropas/`) — supplied by the project owner (pack "retro royale SFX new"), who confirmed permission to use them. Sound effects only (no music or jingles): 43 OGG clips for deploy, attack, hit, death and steps of each troop and the Estalo spell; original file names kept, one folder per card.
- **Impact Sounds** — Kenney, CC0: https://kenney.nl/assets/impact-sounds. Eight original OGG clips; full license in `sfx/LICENSE.txt`.
- **Particle Pack** — Kenney, CC0: https://kenney.nl/assets/particle-pack. Four original PNG textures; full license in `vfx/LICENSE.txt`.
- **Lilita One** — Juan Pablo del Peral, SIL Open Font License 1.1, via Google Fonts. Font and full license in `fonts/`.
